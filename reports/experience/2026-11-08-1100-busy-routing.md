## 1. Ask is never left disabled (`6cb7460`)

- **Cause:** each flow set busy at the start and cleared it by hand at its end. If anything
  threw part-way, nothing cleared it.
- **On mocks:** the card-then-chip sequence worked before the fix too. So I could not reproduce
  the exact failure on the market path, and I don't know which line throws with the live server.
- **Fix:** one wrapper, `busyTurn()`, disables Ask, the chips and the view buttons once, and
  re-enables them in `finally`.
  - That runs after everything is drawn and spoken, on every path, errors included.
  - It covers every flow: typed and chip questions, market cards, idea cards, scenario cards,
    what-if, estimate, tamper and restore.
  - No flow sets busy itself any more; a test pins this.
- **Space:**
  - Before the stamp: it skips to the stamp, as before.
  - After the stamp (the reactions): it now stops the voice, so the turn ends and Ask comes
    back at once.

## 2. A question that maps to nothing (`6cb7460`)

The page now treats these answers as unmapped:
- `claim_id` "NONE" or missing;
- a 200 reply without a claim.

The page used to guess a claim from keywords when the reply had no claim; it no longer does.

What the user sees:
- **Heater's bubble:** the server's `message`, else its `heater_text`, else the fallback "I don't
  call games. Ask me about the hot hand, home advantage, rest, or pick a game from Tonight's games."
- **No Ref card or stamp.**
- **A question that fails part-way** also gets the fallback line instead of silence.

## 3. Game questions on the main screen (`027c418`)

Before the router and the claim path, the typed question is scanned for tonight's teams.
- **How it matches:** case-insensitive, whole words; full name, city or nickname.
- **Where the names come from:** the forecast's own names, with no added aliases. "Sixers" is
  not in the data, so it doesn't match.

| Typed question names | What happens |
|---|---|
| Teams from exactly one of tonight's games | That game's card turn, the same function as the card's Ask (`marketTurn`), on the stage: Heater, Frost, the Ref card and the stamp. The typed question is shown above. No board. |
| Two or more games, or a team not playing tonight | Heater's bubble "Which game? Tonight: 76ers at Bulls, Lakers at Pistons, …", built from the loaded list |
| No team | The existing path, unchanged |

- **Tonight's list:**
  - It's the board's list if the board is loaded.
  - Otherwise the forecast is loaded once (no comparisons), only when a team is named.
- **Teams not playing tonight:** spotting them uses a fixed list of the 30 NBA teams
  (`web/market/game-match.js`).
- **"heat check"** does not count as the Miami Heat.
- **A game with no price or a failed comparison:** Heater says why, with no Ref.
- **Board view:** a typed game question on the board view also runs on the stage.
