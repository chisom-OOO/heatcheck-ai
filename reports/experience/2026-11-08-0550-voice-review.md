## Checked and fine

- **The key stays on the server.** It only ever goes in the `Authorization` header (`transcription.py:151`). Network errors return only the exception type name.
- **The limits agree with each other.** 30 s × 16 kHz × 2 bytes = 960 KB, under the 2 MB cap. The page stops at 30 s; the server allows 30.5 s, which covers recorder lag.
- **Audio is checked strictly and never converted on the server.** WAV only: mono, 16-bit, 16 kHz, uncompressed, at least 0.2 s.
- **Clips are not stored.** The usage log keeps duration, size, status and the stand-in cost, labelled "not a published price".
- **The page server checks the origin on POST** (`_origin_ok`, `app.py:434`) before forwarding. A body over 2 MB is refused with 413 before it is forwarded (tested in `test_api.py`).
- **Max's API answers before it can reset the connection.** It reads the upload before answering, so a 413, 415 or 503 arrives instead of a reset. A cross-site POST that sends `audio/wav` needs a CORS preflight, which only allowed origins pass. A simple `text/plain` POST is refused with 415 before any call to Meta.
- **The keyboard works.** Space or Enter produces a click with `detail === 0`, which toggles recording. A pointer tap's click (`detail ≥ 1`) is ignored, so a tap never toggles twice.
- **The Opera and Brave fallback rule is right.** They are excluded from browser speech (`voiceSupport`); recording still works in them.
- **Experience's code is not affected.** Board, Heater order and Ask are unchanged. All 103 node tests pass, including the market Ask order tests.
