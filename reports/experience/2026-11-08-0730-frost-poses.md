## Issues found

- **Voice clash on Chrome:** `pickVoices` gives the Ref "Google UK English Male", which is Frost's second choice. With Frost on stage, the Ref moves to "Google UK English Female". There is a test for this.
- **Voice clash on Edge:** if Edge lists en-GB voices first, `pickVoices`' Heater pattern matches "Microsoft Ryan Online", which is Frost's first choice. With Frost on stage, Heater moves to Guy. There is a test for this. Without Frost, nothing changes.
- **Same speech settings:** the adviser's Frost settings (rate 0.95, pitch 0.9) are exactly the Ref's `VOICE.ref`, so only the voice keeps them apart. If a browser has only one British voice and no other English voice, Frost and the Ref can sound alike. Max may want to give the Ref a different pitch. I didn't change `VOICE`.
- **Chips give results before the Ref:** in the sample, chips state results before the Ref rules (for example "This one didn't clear it (p = 1.000)"). That is as designed ("result chips"); nothing filters them.
- **No evidence record in the sample:** the sample has no `evidence_record_id`, so the page finds the record by `claim_id` (latest CONF-HH in the ledger). If the ledger lacks it, it uses the API's `verdict` and `ref_text`.
