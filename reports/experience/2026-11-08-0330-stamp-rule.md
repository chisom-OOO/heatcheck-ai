## What Max's API returns, and the stamp

The API has no stamp field. Each effect in a typed what-if (`POST /api/scenario/estimate`) carries `type`
and `included`, and only included effects feed the number (`heatcheck/agents/scenario.py`). The stamp
follows them:

| Answer | Stamp |
|---|---|
| SAMPLE forecast | SAMPLE |
| an included `YOUR_ASSUMPTION` (the user's own adjustment), with a scenario number | **YOUR ASSUMPTION** |
| an included `HYPOTHETICAL_PRICE` (a price the user typed) | **YOUR ASSUMPTION** |
| scenario number from included `ESTIMATE` (Research's data) or `MODEL_RECALC` (the model's own Elo) only | **ESTIMATE** |
| no number (`NO_NUMBER`, or nothing included) | NO NUMBER (Max's own label) |

- A user number beside data effects is still YOUR ASSUMPTION, because part of the number is the user's.
- **Presets** (`GET /api/scenario`): the stamp is the scenario's own `label`, which the page accepts only
  as `ESTIMATE` (SAMPLE when invented). Before, presets were already ESTIMATE and typed what-ifs were a
  fixed "HYPOTHETICAL".
- YOUR ASSUMPTION has its own stamp colour, `.stamp.assumption`.
- Unchanged: Max's `whatif.js` panel (its HYPOTHETICAL badge, which is the API's `label`) and his server's
  `ref_text`.
