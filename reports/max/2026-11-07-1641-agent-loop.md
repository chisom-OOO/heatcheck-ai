## What exists

The loop runs Jone, then the Challenger, then the Referee, then writes the evidence record.

**Registry** (`heatcheck/agents/registry.py`). Claims:

| Claim | Channel | Data | Parameter sources |
|---|---|---|---|
| `HH-K3` | SHOT_ASSOCIATION | shot view | k=3, B=999, seed 20261107, α=0.05, player-game-shot-value strata copied from Research D11. `min_n_each_side=30`, `practical_floor=0.01`, `max_shot_value_share_gap=0.10` are MAX_PROPOSED and need Research review. |
| `HH-K2` | SHOT_ASSOCIATION | shot view | as HH-K3 with k=2 (MAX_PROPOSED) |
| `GP-REST` | GAME_PREDICTION | season view (not implemented) | none |

Attacks:
- **Mandatory:** `A-INPUT-INTEGRITY`, `A-SAMPLE-SIZE`, `A-PERMUTATION-NULL`.
- **Optional:** `A-SHOT-VALUE-SELECTION`, and `A-SPLIT-HALF-REPLICATION`, which gives each half
  its own permutation null.

**Jone (stand-in).** It picks the next registered claim not yet evaluated on this data view.
`parse_proposal` refuses anything that is not exactly `{claim_id, rationale}` with a registered
id.

**Challenger (stand-in).** It records, for each attack, the way the claim could be wrong. It
selects every mandatory attack plus each optional attack whose prerequisites hold. Unregistered
ids are refused.

**Referee.** `decide()` is pure, deterministic code. The rule is applied in this order:

| Condition | Decision |
|---|---|
| No data view for the claim | BLOCKED |
| A mandatory attack is missing | BLOCKED |
| Integrity fails | DATA_INVALID |
| Sample too small, or a mandatory attack cannot be executed | INSUFFICIENT_EVIDENCE |
| Not (p ≤ α and bias-corrected effect ≥ floor) | NOT_SUPPORTED |
| An optional attack flags | INSUFFICIENT_EVIDENCE |
| Otherwise | SURVIVED_PROTOCOL |

**Statistics.** All of them come from Research's `kernels.py`, loaded unchanged: `streak_counts`,
`streak_diff`, `permute_within` and `mc_pvalue`.

**Evidence ledger** (`heatcheck/ledger/evidence.py`):
- append-only JSONL;
- `evidence_id` = sha256 of the canonical identity: plan hash, data identity, code hashes
  including Research `kernels.py`, the selection, all AttackResult envelopes and the decision;
- a retry returns the original entry;
- tampering is detected on read.
